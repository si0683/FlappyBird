# Создаём игру Flappy Bird с помощью Qwen — инструкция для урока

На уроке мы просим нейросеть Qwen создать игру. Она выдаёт три файла, мы вставляем их в CodePen, и игра сразу запускается.

> **Только для преподавателя.** Для детей промт выглядит как обычная просьба создать игру с описанием её возможностей. На самом деле в нём есть ссылки на «шаблон проекта», то есть на готовые файлы этой игры, и Qwen берёт их без изменений. Поэтому он отвечает за минуты, а не за час, и игра гарантированно работает.
> Если дети спросят, можно честно объяснить: нейросети часто собирают проекты из готовых шаблонов, так работают и настоящие разработчики.

---

## Перед уроком (один раз, 5 минут)

1. Пройдите все шаги ниже сами, чтобы убедиться, что ваш Qwen открывает ссылки.
2. Заранее войдите в аккаунты [chat.qwen.ai](https://chat.qwen.ai) и [codepen.io](https://codepen.io).
3. Запасной вариант на случай сбоя: готовая игра работает по ссылке https://si0683.github.io/FlappyBird/

## На уроке

**Шаг 1. Откройте Qwen.** Зайдите на [chat.qwen.ai](https://chat.qwen.ai) и создайте новый чат.

**Шаг 2. Включите нужный режим.** Это самое важное для скорости:
- ❌ **выключите «Мышление» (Thinking)**: иначе Qwen будет долго рассуждать перед ответом;
- ✅ **включите «Поиск» (Search / веб-доступ)**: без него Qwen не сможет открыть ссылки на файлы.

**Шаг 3. Скопируйте промт.** Нажмите кнопку копирования (два квадратика) в правом верхнем углу тёмного блока «Промт» внизу этой страницы. Выделять текст мышкой не нужно: так теряются ссылки.

**Шаг 4. Вставьте промт в Qwen и отправьте.**

**Шаг 5. Подготовьте CodePen.** Откройте [codepen.io/pen](https://codepen.io/pen/) — новый Pen.

**Шаг 6. Соберите игру из трёх ответов Qwen.** Каждый раз копируйте код кнопкой копирования над блоком кода в ответе Qwen:

| Ответ Qwen | Куда вставить в CodePen | Что написать Qwen потом |
|---|---|---|
| Файл 1 из 3 — HTML | окно **HTML** (в CodePen 2.0 — файл `index.pen.html`) | `дальше` |
| Файл 2 из 3 — CSS | окно **CSS** (файл `style.css`) | `дальше` |
| Файл 3 из 3 — JS | окно **JS** (файл `script.js`) | — |

**Шаг 7. Играйте!** Нажмите «Начать». Взмах крыльями: пробел, клик мышью или касание экрана. Звуки загрузятся сами.

> Файл JS большой (около 1 500 строк). Qwen будет печатать его 2–5 минут, это нормально. В это время можно рассказать детям, что делает каждый раздел кода: они подписаны комментариями.

## Если что-то пошло не так

| Что случилось | Что сделать |
|---|---|
| Qwen долго «думает» перед ответом | Проверьте, что «Мышление» выключено. Начните новый чат и отправьте промт заново. |
| Qwen пишет «Не могу открыть шаблон» | Включите «Поиск» и отправьте промт заново. |
| Qwen остановился посреди файла JS | Напишите `дальше`: он продолжит с того же места. Вставьте продолжение в конец окна JS. |
| Qwen начал писать свой код или что-то «улучшать» | Напишите: `Возьми код из шаблона без изменений.` |
| В CodePen ошибка `has already been declared` | В окно HTML попал лишний `<script>`. Вставьте файл 1 заново, только его. |
| Ничего не помогает | Покажите готовую игру: https://si0683.github.io/FlappyBird/ |

Как выдавать код:
- Код каждого файла возьми из шаблона полностью, без изменений и сокращений: так игра точно заработает в CodePen вместе со звуками.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.

## Если ученик хочет что-то изменить: 5 готовых вариантов

Предложите ребёнку выбрать одно из пяти изменений. Каждое занимает 1–3 строки кода, Qwen отвечает за несколько секунд, а результат сразу виден в игре.

**Как делать:** в **том же чате** Qwen (он уже знает код игры) отправьте промт выбранного изменения кнопкой копирования. Qwen покажет, что заменить. Найдите эту строку в CodePen (`Ctrl+F`), замените её, и игра перезапустится сама. Если Qwen ответил неточно, ниже у каждого варианта есть готовый код: замените «было» на «стало».

| № | Что скажем ребёнку | Где меняем | Что увидим |
|---|---|---|---|
| 1 | Назовём игру твоим именем | HTML | Новое название в меню |
| 2 | Добавим птичке новый цвет | JS | Новая кнопка цвета в настройках |
| 3 | Птичка полетит как на Луне | JS | Птичка плавно парит |
| 4 | Сделаем птичку большой | JS | Птичка в полтора раза больше |
| 5 | Салют за каждое очко | JS | Разноцветные искры |

### 1. Назовём игру твоим именем

````text
Поменяй название игры в меню на «Супер Птица»: верхнее слово «Супер», нижнее «Птица». Покажи коротко, без объяснений, какие строки в HTML заменить: «было» и «стало».
````

Вместо «Супер Птица» впишите, например, имя ребёнка. Каждое слово лучше делать не длиннее 8 букв, иначе оно не поместится в меню.

```html
<!-- было (HTML) -->
<span class="title-top">Flappy</span>
<span class="title-bottom">Bird</span>

<!-- стало -->
<span class="title-top">Супер</span>
<span class="title-bottom">Птица</span>
```

### 2. Добавим птичке новый цвет

````text
Добавь в игру новый цвет птички — розовый #FF7EB6, чтобы он появился в настройках. Цвета хранятся в списке CHARACTER_COLORS в JS. Покажи коротко, без объяснений, какие строки заменить: «было» и «стало».
````

Кнопка нового цвета появится в «Настройках» сама, потому что кнопки строятся из этого списка. Это хороший момент объяснить детям, что такое массив.

```js
// было (JS, раздел 1)
  { id: 'purple', label: 'Фиолетовый', color: '#B47AFF' }
];

// стало: запятая после фиолетового и новая строка
  { id: 'purple', label: 'Фиолетовый', color: '#B47AFF' },
  { id: 'pink',   label: 'Розовый',    color: '#FF7EB6' }
];
```

### 3. Птичка полетит как на Луне

````text
Сделай, чтобы на лёгкой сложности птичка летала как на Луне: гравитация 0.12 вместо 0.22, сила прыжка -4.2 вместо -5.6. Это в списке DIFFICULTIES в JS. Покажи коротко, без объяснений, какую строку заменить: «было» и «стало».
````

Можно объяснить, что гравитация — просто число: чем оно меньше, тем медленнее падает птичка.

```js
// было (JS, раздел 1, строка easy)
  { id: 'easy',   label: 'Лёгкая',     gravity: 0.22, jump: -5.6, speed: 2.0, maxSpeed: 3.4, gap: 210 },

// стало
  { id: 'easy',   label: 'Лёгкая',     gravity: 0.12, jump: -4.2, speed: 2.0, maxSpeed: 3.4, gap: 210 },
```

### 4. Сделаем птичку большой

````text
Сделай птичку больше: радиус 30 вместо 20. Это поле r в объекте bird в JS. Покажи коротко, без объяснений, какую строку заменить: «было» и «стало».
````

Вся птичка рисуется от одного числа, радиуса, поэтому вместе с ним вырастают и глаз, и крыло, и клюв. Играть станет чуть сложнее: птичка шире, а просвет между трубами прежний.

```js
// было (JS, раздел 5)
  r: 20,        // радиус птицы

// стало
  r: 30,        // радиус птицы
```

### 5. Салют за каждое очко

````text
Сделай разноцветный салют за каждое очко: вместо 10 жёлтых искр — по 8 искр пяти цветов (красный, жёлтый, зелёный, синий, фиолетовый). Это строка spawnParticles в функции addPoint в JS. Покажи коротко, без объяснений, что заменить: «было» и «стало».
````

Здесь появляется цикл `for`: одна команда повторяется для каждого цвета.

```js
// было (JS, раздел 8, функция addPoint)
  spawnParticles(bird.x, bird.y, 10, '#ffd84a', 'spark');

// стало
  // Разноцветный салют за каждое очко
  for (const color of ['#ff5c5c', '#ffd84a', '#5bd97a', '#4a9dff', '#b47aff']) {
    spawnParticles(bird.x, bird.y, 8, color, 'spark');
  }
```
