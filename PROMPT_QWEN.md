# Создаём игру Flappy Bird с помощью Qwen — инструкция для урока

На уроке мы просим нейросеть Qwen создать игру. Она выдаёт три файла, мы вставляем их в CodePen, и игра сразу запускается.

> **Только для преподавателя.** Для детей промт выглядит как обычная просьба создать игру с описанием её возможностей. На самом деле в нём есть ссылки на «шаблон проекта», то есть на готовые файлы этой игры, и Qwen берёт их без изменений. Поэтому он отвечает за минуты, а не за час, и игра гарантированно работает.
> Если дети спросят, можно честно объяснить: нейросети часто собирают проекты из готовых шаблонов, так работают и настоящие разработчики.

---

## Перед уроком (один раз, 5 минут)

1. Пройдите все шаги ниже сами, чтобы убедиться, что ваш Qwen открывает ссылки.
2. Заранее войдите в аккаунты [chat.qwen.ai](https://chat.qwen.ai) и [codepen.io](https://codepen.io).
3. Запасной вариант на случай сбоя: готовая игра работает по ссылке https://si0683.github.io/FlappyBird/

## На уроке

**Шаг 1. Откройте Qwen.** Зайдите на [chat.qwen.ai](https://chat.qwen.ai) и создайте новый чат.

**Шаг 2. Включите нужный режим.** Это самое важное для скорости:
- ❌ **выключите «Мышление» (Thinking)**: иначе Qwen будет долго рассуждать перед ответом;
- ✅ **включите «Поиск» (Search / веб-доступ)**: без него Qwen не сможет открыть ссылки на файлы.

**Шаг 3. Скопируйте промт.** Нажмите кнопку копирования (два квадратика) в правом верхнем углу тёмного блока «Промт» внизу этой страницы. Выделять текст мышкой не нужно: так теряются ссылки.

**Шаг 4. Вставьте промт в Qwen и отправьте.**

**Шаг 5. Подготовьте CodePen.** Откройте [codepen.io/pen](https://codepen.io/pen/) — новый Pen.

**Шаг 6. Соберите игру из трёх ответов Qwen.** Каждый раз копируйте код кнопкой копирования над блоком кода в ответе Qwen:

| Ответ Qwen | Куда вставить в CodePen | Что написать Qwen потом |
|---|---|---|
| Файл 1 из 3 — HTML | окно **HTML** (в CodePen 2.0 — файл `index.pen.html`) | `дальше` |
| Файл 2 из 3 — CSS | окно **CSS** (файл `style.css`) | `дальше` |
| Файл 3 из 3 — JS | окно **JS** (файл `script.js`) | — |

**Шаг 7. Играйте!** Нажмите «Начать». Взмах крыльями: пробел, клик мышью или касание экрана. Звуки загрузятся сами.

> Файл JS большой (около 1 500 строк). Qwen будет печатать его 2–5 минут, это нормально. В это время можно рассказать детям, что делает каждый раздел кода: они подписаны комментариями.

## Если что-то пошло не так

| Что случилось | Что сделать |
|---|---|
| Qwen долго «думает» перед ответом | Проверьте, что «Мышление» выключено. Начните новый чат и отправьте промт заново. |
| Qwen пишет «Не могу открыть шаблон» | Включите «Поиск» и отправьте промт заново. |
| Qwen остановился посреди файла JS | Напишите `дальше`: он продолжит с того же места. Вставьте продолжение в конец окна JS. |
| Qwen начал писать свой код или что-то «улучшать» | Напишите: `Возьми код из шаблона без изменений.` |
| В CodePen ошибка `has already been declared` | В окно HTML попал лишний `<script>`. Вставьте файл 1 заново, только его. |
| Ничего не помогает | Покажите готовую игру: https://si0683.github.io/FlappyBird/ |

     Промт должен выглядеть для детей как просьба создать игру; ссылки на файлы — «шаблон проекта». Не писать «скопируй дословно». -->

````text
Создай браузерную игру Flappy Bird для CodePen.

- красивая мультяшная графика, анимации и звуки;
- работает и на компьютере, и на телефоне.

Собери проект на основе моего готового шаблона: в нём уже есть графика, звуки и настройки.
HTML: https://raw.githubusercontent.com/si0683/FlappyBird/main/codepen/index.pen.html
CSS: https://raw.githubusercontent.com/si0683/FlappyBird/main/style.css
JS: https://raw.githubusercontent.com/si0683/FlappyBird/main/script.js
Запасные адреса шаблона:
https://si0683.github.io/FlappyBird/codepen/index.pen.html
https://si0683.github.io/FlappyBird/style.css
https://si0683.github.io/FlappyBird/script.js

Как выдавать код:
- Код каждого файла возьми из шаблона полностью, без изменений и сокращений: так игра точно заработает в CodePen вместе со звуками.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.
- Перед каждым блоком кода напиши одну строку:

- JS длинный: если он не помещается в один ответ, остановись в конце строки. После «дальше» продолжи со следующей строки новым блоком кода.
- Если шаблон не открывается, напиши «Не могу открыть шаблон».
````

## Если ученик хочет что-то изменить: «Лаборатория», 10 вариантов

В самом начале файла JS есть блок **«0. ЛАБОРАТОРИЯ ИГРЫ 🧪»**: 10 настроек, каждая на своей строке и с подсказкой в комментарии. Сейчас там обычные значения, и игра работает как задумано.

Предложите ребёнку выбрать одно изменение из таблицы. Каждое — **одно значение в одной строке**, а результат сразу виден в игре.

**Как делать:**
1. В **том же чате** Qwen (он уже знает код игры) отправьте промт выбранного варианта кнопкой копирования.
2. Qwen покажет строку «было → стало».
3. В CodePen в окне JS нажмите `Ctrl+F`, найдите строку «было» и замените значение. Игра перезапустится сама.

Если Qwen ответит неточно, просто поменяйте значение сами: строки «было» и «стало» есть у каждого варианта ниже. Можно включать несколько вариантов сразу.

| № | Что предложить ребёнку | Строка в Лаборатории | Было → стало |
|---|---|---|---|
| 1 | Назовём игру твоим именем | `titleTop` | `titleTop: 'Flappy', titleBottom: 'Bird'` → `titleTop: 'Супер', titleBottom: 'Птица'` |
| 2 | Свой цвет птички | `myBirdColor` | `myBirdColor: ''` → `myBirdColor: '#FF7EB6'` |
| 3 | Птичка полетит как на Луне | `gravity` | `gravity: 1` → `gravity: 0.5` |
| 4 | Большая птичка | `birdSize` | `birdSize: 20` → `birdSize: 30` |
| 5 | Турбо-режим | `gameSpeed` | `gameSpeed: 1` → `gameSpeed: 1.5` |
| 6 | Широкие проходы | `gapBonus` | `gapBonus: 0` → `gapBonus: 60` |
| 7 | Трубы чаще | `obstacleDistance` | `obstacleDistance: 270` → `obstacleDistance: 200` |
| 8 | Огромные очки | `pointsPerObstacle` | `pointsPerObstacle: 1` → `pointsPerObstacle: 100` |
| 9 | Салют за каждое очко | `fireworks` | `fireworks: false` → `fireworks: true` |
| 10 | Радужный хвост | `rainbowTrail` | `rainbowTrail: false` → `rainbowTrail: true` |

### 1. Назовём игру твоим именем

````text
Назови игру «Супер Птица»: верхнее слово «Супер», нижнее «Птица». Это в блоке LAB в начале JS. Покажи коротко, без объяснений, строку «было» и «стало».
````

Впишите имя ребёнка. Каждое слово — не длиннее 8 букв, иначе не поместится в меню.

```js
// было
  titleTop: 'Flappy',
  titleBottom: 'Bird',

// стало
  titleTop: 'Супер',
  titleBottom: 'Птица',
```

### 2. Свой цвет птички

````text
Добавь птичке свой цвет — розовый #FF7EB6. Это в блоке LAB в начале JS. Покажи коротко, без объяснений, строку «было» и «стало».
````

В «Настройках» появится кнопка «Мой цвет», её нужно нажать. Цвет можно подобрать в любом «color picker» в интернете.

```js
// было
  myBirdColor: '',

// стало
  myBirdColor: '#FF7EB6',
```

### 3. Птичка полетит как на Луне

````text
Сделай, чтобы птичка летала как на Луне — гравитация в 2 раза меньше. Это в блоке LAB в начале JS. Покажи коротко, без объяснений, строку «было» и «стало».
````

Попробуйте и 2: это Юпитер, там всё тяжёлое. Высота взмаха не меняется, меняется только плавность.

```js
// было
  gravity: 1,

// стало
  gravity: 0.5,
```

### 4. Большая птичка

````text

````
