# Flappy Bird

Браузерная игра на чистом HTML, CSS и JavaScript: без библиотек и без сборки.
Сделана для уроков программирования, поэтому код подробно прокомментирован на русском.

**Играть:** https://si0683.github.io/FlappyBird/

## Управление

| Действие | Клавиши |
|---|---|
| Взмах крыльями | `Пробел`, `↑`, `W`, клик мышью или касание экрана |
| Пауза | `Esc` или `P`, кнопка ⏸ |

## Возможности

- Стартовое меню, отсчёт 3-2-1, пауза, экран «Игра окончена».
- Жизни (сердечки) и 1,5 секунды неуязвимости после удара: птица в это время мигает. Задетое препятствие рассыпается, поэтому птица никогда не пролетает сквозь него.
- Игра плавно ускоряется каждые 10 очков.
- Рекорд и настройки сохраняются в браузере.
- Настройки: цвет птицы, трубы или колонны, цвет препятствий, 4 фона (дневное небо, космос, ночной город, горы), сложность, число жизней, звук и громкость, режим тренировки.
- Работает на компьютере и на телефоне.

## Файлы

```
index.html   — разметка: холст и экраны (меню, настройки, пауза, конец игры)
style.css    — оформление: цвета, шрифты, кнопки, анимации
script.js    — логика: физика, препятствия, столкновения, рисование
sounds/      — звуки: flap, score, tick, start, hit
PROMPT.md    — промт для нейросети: подробное ТЗ + полные исходники + ссылки на звуки
PROMPT_QWEN.md — короткий промт (~11 000 символов) для Qwen и других чатов с ограничением: ссылки на исходники + сжатое ТЗ
AGENTS.md    — правила для ИИ-агентов (PROMPT.md обновляется вместе с игрой)
codepen/index.pen.html — готовый HTML для CodePen (создаётся автоматически)
tools/build.py — обновляет исходники в PROMPT.md и файл codepen/index.pen.html
```

Чтобы другая нейросеть собрала эту игру, отдайте ей файл `PROMPT.md` целиком: по нему получится точная копия.
Если чат не принимает такой длинный текст (например, Qwen), используйте `PROMPT_QWEN.md`. В нём ссылки на все исходники на GitHub и сжатое ТЗ. Чтобы нейросеть могла открыть ссылки, включите в чате поиск в интернете. Файлы она выдаёт по очереди, после каждого напишите ей «дальше». Звуки возьмите из папки `sounds/`.
После любого изменения кода обновите исходники в PROMPT.md и файл для CodePen:

```bash
python tools/build.py
```

`script.js` разбит на 14 пронумерованных разделов, читать его удобно сверху вниз.
Всё, что отвечает за физику (гравитация, сила прыжка, скорость, ширина просвета), собрано в массиве `DIFFICULTIES` в начале файла. Дети могут менять там числа и сразу видеть результат.

## Запуск на компьютере

Звук играет через Web Audio, а он загружает файлы только с сервера. Если открыть `index.html` двойным щелчком, игра работает, но без звука. Поэтому запустите простой сервер из папки игры:

```bash
python -m http.server 8000
```

После этого откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий `https://github.com/si0683/FlappyBird`.
2. В репозитории откройте **Settings → Pages → Source: Deploy from a branch**, выберите ветку `main` и папку `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://si0683.github.io/FlappyBird/`.

## Публикация на CodePen

| Файл в CodePen | Что вставить |
|---|---|
| `index.pen.html` (в классическом CodePen — окно HTML) | весь файл **`codepen/index.pen.html`** (не `index.html`!) |
| `style.css` | весь `style.css` |
| `script.js` | весь `script.js` |

⚠️ Не вставляйте в CodePen `index.html`. CodePen сам подключает `style.css` и `script.js`, а в `index.html` они подключены ещё раз. Скрипт загрузится дважды, и появится ошибка `Identifier 'CHARACTER_COLORS' has already been declared`. В `codepen/index.pen.html` лишних строк нет, его можно вставлять целиком.

Звуки в CodePen загружаются с GitHub Pages: игра сама определяет, что запущена в CodePen (константа `SOUND_PATH` в разделе 3). Поэтому сначала опубликуйте игру на GitHub Pages.
