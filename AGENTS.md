# AGENTS.md — правила для ИИ-агентов

Игра для уроков программирования с детьми. Перед работой прочитай `README.md` и `PROMPT.md`.

## Главное правило: PROMPT.md всегда соответствует игре

`PROMPT.md` — техническое задание, по которому другая нейросеть должна собрать **точно такую же** игру.
Любое изменение поведения, чисел, графики, интерфейса, звуков или структуры файлов в том же изменении
отражается в `PROMPT.md`, а при необходимости и в `README.md`.

- Поменял число (физика, размеры, тайминги, цвета) — поправь его в `PROMPT.md`.
- Добавил или убрал настройку, экран, звук или функцию — добавь или убери в `PROMPT.md`.
- Исправил баг — опиши правильное поведение в `PROMPT.md` с пометкой ⚠️, чтобы другая нейросеть не повторила ошибку.
- В конце `PROMPT.md` лежат **полные исходники** (между метками `SOURCES:START` и `SOURCES:END`).
  Руками их не править: после любого изменения `index.html`, `style.css` или `script.js` запусти
  `python tools/build.py`. Он вставит актуальный код и пересоберёт `codepen/index.pen.html`.
- `codepen/index.pen.html` тоже руками не править: он вырезается из `index.html` по меткам «Для CodePen».
- Добавил, убрал или переименовал звук — обнови таблицу «Звуковые файлы» в `PROMPT.md`.
- `PROMPT_QWEN.md` — инструкция для урока. Для детей промт выглядит как просьба создать игру, а ссылки на файлы
  поданы как «шаблон проекта» (слов «скопируй дословно» в промте быть не должно). На деле Qwen быстро, без
  «размышлений» берёт готовые файлы по ссылкам
  (HTML для CodePen — `codepen/index.pen.html`, затем `style.css`, затем `script.js`) и отдаёт их по одному.
  ТЗ там нет, поэтому при правках игры его менять не нужно. Исключения: переименовал или добавил файл, изменил
  порядок вставки в CodePen или заметно изменил размер `script.js` — поправь ссылки, таблицу шагов и
  оценку «около N строк».
  Промт лежит внутри блока ````text: GitHub показывает у блока кнопку копирования и отдаёт текст вместе со ссылками.
  Если копировать оформленную страницу, ссылки теряются при вставке в чат. Блок не убирать, промт держать коротким.
  Весь промт — ОДИН блок в начале файла (пользователь копирует его одной кнопкой): создание игры + список
  10 изменений через объект `LAB` («Лаборатория», раздел 0 в начале `script.js`). Ниже — таблица
  «10 изменений» с «было/стало». Значения `LAB` по умолчанию должны давать обычную игру. Поменял поле `LAB`
  (имя, значение по умолчанию, формат строки) — обнови и список в промте, и таблицу, иначе на уроке Ctrl+F ничего не найдёт.
- Перед коммитом: номер `?v=` увеличен, `python tools/build.py` запущен, ТЗ в `PROMPT.md` сверено с кодом.

## Номер версии в index.html

GitHub Pages разрешает браузеру хранить файлы в кэше 10 минут. Чтобы игроки сразу получали обновление,
`style.css` и `script.js` подключаются с номером версии: `style.css?v=3`, `script.js?v=3`.

- При **любом** изменении `style.css` или `script.js` увеличь номер на 1 **в обеих** строках `index.html`
  (номер у обоих файлов всегда одинаковый).
- Номер в комментарии `index.html` и пример в `PROMPT.md` менять не нужно: там описано правило, а не текущая версия.

## Ограничения кода

- Только чистые HTML, CSS и JS в трёх отдельных файлах. Никаких библиотек, фреймворков и сборки.
- Простой код для детей: объекты и функции, без классов и модулей. Подробные комментарии на русском.
- Код должен без правок вставляться в CodePen: HTML — из `codepen/index.pen.html`, плюс `style.css` и `script.js`.

## Проверка

Запусти сервер из папки игры (`python -m http.server 8123`), открой http://localhost:8123.
Проверь меню, настройки, все фоны, игру, потерю жизней и экран «Игра окончена». В консоли не должно быть ошибок.
