# AGENTS.md — правила для ИИ-агентов

Игра для уроков программирования с детьми. Перед работой прочитай `README.md` и `PROMPT.md`.

## Главное правило: PROMPT.md всегда соответствует игре

`PROMPT.md` — техническое задание, по которому другая нейросеть должна собрать **точно такую же** игру.
Любое изменение поведения, чисел, графики, интерфейса, звуков или структуры файлов в том же изменении
отражается в `PROMPT.md`, а при необходимости и в `README.md`.

- Поменял число (физика, размеры, тайминги, цвета) — поправь его в `PROMPT.md`.
- Добавил или убрал настройку, экран, звук или функцию — добавь или убери в `PROMPT.md`.
- Исправил баг — опиши правильное поведение в `PROMPT.md` с пометкой ⚠️, чтобы другая нейросеть не повторила ошибку.
- Перед коммитом сверь `PROMPT.md` с `script.js`, `index.html` и `style.css` и проверь, что номер версии `?v=` увеличен.

## Номер версии в index.html

GitHub Pages разрешает браузеру хранить файлы в кэше 10 минут. Чтобы игроки сразу получали обновление,
`style.css` и `script.js` подключаются с номером версии: `style.css?v=3`, `script.js?v=3`.

- При **любом** изменении `style.css` или `script.js` увеличь номер на 1 **в обеих** строках `index.html`
  (номер у обоих файлов всегда одинаковый).
- Номер в комментарии `index.html` и пример в `PROMPT.md` менять не нужно: там описано правило, а не текущая версия.

## Ограничения кода

- Только чистые HTML, CSS и JS в трёх отдельных файлах. Никаких библиотек, фреймворков и сборки.
- Простой код для детей: объекты и функции, без классов и модулей. Подробные комментарии на русском.
- Код должен без правок вставляться в три окна CodePen.

## Проверка

Запусти сервер из папки игры (`python -m http.server 8123`), открой http://localhost:8123.
Проверь меню, настройки, все фоны, игру, потерю жизней и экран «Игра окончена». В консоли не должно быть ошибок.
